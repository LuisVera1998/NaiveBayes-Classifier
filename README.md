# Naive Bayes Classifier

An academic Machine Learning project developed at the **Universitat Autònoma de Barcelona (UAB)** as part of the Computer Engineering degree.

The project focuses on the study and application of the **Naive Bayes classification algorithm**, exploring probabilistic classification techniques and their use in supervised learning.

## Project Overview

The main objective of this project is to gain practical experience with probabilistic Machine Learning methods, particularly the Naive Bayes classifier.

The repository includes a Jupyter Notebook containing the practical work and a PDF report documenting the methodology, analysis and conclusions.

## Technologies

- **Python** – Programming language
- **Jupyter Notebook** – Interactive development and experimentation
- **Naive Bayes** – Probabilistic classification algorithm

## Repository Contents

- **Jupyter Notebook:** Source code and practical experimentation with Naive Bayes classification.
- **PDF Report:** Academic report describing the project, methodology and conclusions.

## Academic Context

This project was developed as part of the Computer Engineering degree at the Universitat Autònoma de Barcelona (UAB).

Its purpose was to explore probabilistic classification methods and strengthen practical knowledge of Machine Learning algorithms.

## Project Status

Completed academic project. The repository preserves the original practical work and its accompanying report for educational and portfolio purposes.
